# Flutter & Dart Practice CLI

A command-line tool built using Dart to practice core concepts, command-line arguments, and external API interactions.

---

## Features & Commands
- `version` - Displays the current version of the CLI tool.
- `help` - Lists all available commands.
- `search <query>` - Searches Wikipedia for the specified topic.
